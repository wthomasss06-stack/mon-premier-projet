## 🚀 Installation & Utilisation

### Prérequis
- Navigateur moderne (Chrome, Firefox, Safari, Edge)
- Serveur web local (optionnel pour développement)



### Personnalisation

1. **Informations personnelles** : Modifier les données dans `index.html`
2. **Thèmes** : Ajuster les variables CSS dans `styles.css`
3. **Projets** : Ajouter de nouveaux projets dans la section `#projects`
4. **Images** : Remplacer les images dans le dossier `images/`
